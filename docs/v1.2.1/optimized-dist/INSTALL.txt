Clarity 1.2.1 — GPU 영상 보정

1. ZIP을 압축 해제합니다.
2. Chrome의 chrome://extensions 또는 Edge의 edge://extensions 를 엽니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 선택합니다.
4. 이 파일과 manifest.json이 들어 있는 폴더를 선택합니다.
5. 설치·업데이트 후 유튜브 탭을 반드시 새로고침합니다.

기본값: 영상 보정·자동 성능 조절 켜짐, 목표 1080p, FPS 원본, 채도·밝기 100%.
목표 해상도: 원본 / 720p / 1080p / 1440p / 4K.
목표 FPS: 원본 / 75 / 100 / 120. 움직임 보간은 WebGPU에서 지원됩니다.
목표는 상한이며 실제 제출 FPS를 확인하세요. 물리 표시 FPS는 측정하지 않습니다.
원본 보기·좌우 비교에서는 같은 원본 프레임을 비교하기 위해 보간을 생략합니다.

보간 제출 시 원본 표시 시각 대비 추가 지연을 45ms 이내로 검사합니다.
video.currentTime 대비 전체 시간차는 더 클 수 있으며 제출 전 100ms 상한도 검사합니다.
출력 사이의 화면 유지 시간은 별도입니다. 오디오는 유튜브 재생을 유지하며
실제 표시·오디오의 정확한 동기화는 보장하지 않습니다.
낮은 FPS, 시간 동기화 실패, 성능 부족, CORS·DRM 제한에서는 보간을 생략하거나
원본 플레이어로 복귀합니다. 보안 정책을 우회하지 않습니다.
Anime4K·신경망·최고 단계는 미지원입니다. SDR 영상으로 사용하세요.

오프라인 진단: 확장 프로그램 ID를 확인한 뒤
chrome-extension://확장프로그램ID/harness/index.html 을 엽니다.
포함된 샘플은 명시적인 합성 진단 영상입니다. 영상 파일은 업로드하지 않습니다.
